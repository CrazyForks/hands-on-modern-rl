# 第 29 章 · 自我博弈、规模化与未来方向

从第 1 章的 CartPole 到第 16 章的 GRPO，我们走过了现代 RL 的核心旅程。你学会了 Q-Learning 和 DQN 如何让智能体从试错中学习，策略梯度如何直接优化行为，PPO 如何稳定地训练大模型，GRPO 如何用可验证奖励激发推理能力。第 20 章的 Agentic RL 把 RL 从"单轮对话"推进到了"多轮工具交互"。

但 RL 的故事远没有结束。2025-2026 年，自博弈开始从棋类迁移到语言模型，多智能体协作把单个策略扩展为角色化系统，训练规模与推理规模也开始共同决定模型能力。本章沿着这三条变化展开，并在最后讨论进化式搜索如何用于算法与科学发现。

本章不追求覆盖所有前沿——那是不可能的。我们挑选了几个最具代表性的方向，每个方向都和前面章节学过的概念紧密相连。你将看到：前面打下的理论基础，在这些前沿方向中反复出现。
