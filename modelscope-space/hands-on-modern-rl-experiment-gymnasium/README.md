# Hands-On Modern RL · Gymnasium CPU Playground

《动手学现代强化学习》的多实验在线训练合集。全部实验使用 CPU，可在浏览器中切换环境、调整参数、查看实时训练曲线与自动跟随最新内容的训练日志。

首批实验：

- Multi-Armed Bandit：探索与利用
- GridWorld：Q-Learning 与价值传播
- FrozenLake：随机转移与稀疏奖励
- MountainCar：延迟奖励与蓄力行为
- Pendulum：连续动作控制
